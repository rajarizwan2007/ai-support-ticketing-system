Introduction

Create, list, show and reply to support tickets in your organization.

Base URL: http://acme.localhost:8088 
Each organization has its own subdomain, and API requests go to it: `http://acme.localhost:8088/api/v1/...`.
A token only works on the subdomain of the organization it was created in.

Requests are limited to 60 per minute per user (or per IP before login). Over the limit you get `429 Too Many Requests`.

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_API_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Get a token from POST /api/v1/tokens with your email and password.

Authentication

Create a token

Log in with email and password and get a token for the Authorization header.

Example request:
curl --request POST \
    "http://acme.localhost:8088/api/v1/tokens" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"email\": \"gbailey@example.net\",
    \"password\": \"|]|{+-\",
    \"device_name\": \"v\"
}"

const url = new URL(
    "http://acme.localhost:8088/api/v1/tokens"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "email": "gbailey@example.net",
    "password": "|]|{+-",
    "device_name": "v"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Example response (201):

    "token": "1|aBcDeFgHiJkLmNoPqRsTuVwXyZ"
}

Tickets

List tickets

requires authentication

Newest first, 20 per page.

Example request:
curl --request GET \
    --get "http://acme.localhost:8088/api/v1/tickets?status=closed" \
    --header "Authorization: Bearer {YOUR_API_TOKEN}" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://acme.localhost:8088/api/v1/tickets"
);

const params = {
    "status": "closed",
};
Object.keys(params)
    .forEach(key => url.searchParams.append(key, params[key]));

const headers = {
    "Authorization": "Bearer {YOUR_API_TOKEN}",
    "Content-Type": "application/json",
    "Accept": "application/json",
};


fetch(url, {
    method: "GET",
    headers,
}).then(response => response.json());

Reply to a ticket

requires authentication

Example request:
curl --request POST \
    "http://acme.localhost:8088/api/v1/tickets/2/messages" \
    --header "Authorization: Bearer {YOUR_API_TOKEN}" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"body\": \"b\",
    \"internal\": true
}"

const url = new URL(
    "http://acme.localhost:8088/api/v1/tickets/2/messages"
);

const headers = {
    "Authorization": "Bearer {YOUR_API_TOKEN}",
    "Content-Type": "application/json",
    "Accept": "application/json",
};

    "body": "b",
    "internal": true
